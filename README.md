# مسابقة نبروه الكبرى للقرآن الكريم والسنة النبوية

الموقع الرسمي لمسابقة نبروه الكبرى، وهي مسابقة سنوية بمحافظة الدقهلية تهدف إلى تشجيع الناشئة والشباب على حفظ القرآن الكريم وإتقان تلاوته، واكتشاف المواهب القرآنية وتكريم المتفوقين.

## العرض المباشر

يمكنك زيارة الموقع من خلال الرابط التالي:

[افتح الموقع التجريبي المباشر](https://mo-mahmoud-dev.github.io/Nabaruh-Quran-Recitation-Competition/)

## صفحات الموقع ومميزاته

- **الصفحة الرئيسية:** تقدم نبذة عن المسابقة ورؤيتها وأهدافها، وتتيح الوصول السريع إلى نموذج التسجيل.
- **التسجيل الإلكتروني:** يجمع بيانات المتسابق، مثل الاسم والعمر والجنس ومستوى الحفظ ورقم الهاتف والعنوان واسم الشيخ المحفّظ.
- **مستويات المشاركة:** القرآن الكريم كاملًا مع تفسير سورة النور ومعاني كلماتها، أو القرآن كاملًا، أو نصف القرآن، أو ربعه، أو الأربعون النووية.
- **التحقق من التسجيل:** التسجيل متاح لسكان مدينة نبروه، ويتحقق الموقع من المشاركين السابقين ومستوى الحفظ المطلوب لهم.
- **المرفقات:** صورة البطاقة أو شهادة الميلاد مطلوبة، والصورة الشخصية مطلوبة للمتسابقين الذكور واختيارية للمتسابقات.
- **إنشاء ملف التسجيل:** يجمع الموقع البيانات والمرفقات في ملف PDF قبل إرسال الطلب.
- **صفحة عن المسابقة:** تعرض رسالتها وأهدافها، والمتسابقين الأوائل، وفيديو من العام الأول.
- **صفحة النتائج:** مخصصة لإعلان النتائج الرسمية.
- **تصميم عربي متجاوب:** واجهة من اليمين إلى اليسار، تدعم الشاشات المختلفة وتتضمن قائمة تنقل مناسبة للهواتف.

## التقنيات المستخدمة

- HTML لبناء صفحات الموقع.
- CSS لتنسيق الواجهة ودعم التصميم المتجاوب.
- JavaScript للتحقق من البيانات والتفاعل مع نموذج التسجيل وتجهيز ملف PDF.
- [jsPDF](https://github.com/parallax/jsPDF) و[html2canvas](https://html2canvas.hertzen.com/) لإنشاء ملف PDF من بيانات التسجيل والمرفقات.
- [FormSubmit](https://formsubmit.co/) لاستقبال طلبات التسجيل.
- Tailwind CSS عبر CDN لتنسيق صفحة النتائج.

## تشغيل الموقع محليًا

الموقع ثابت ولا يحتاج إلى تثبيت حزم أو تشغيل خادم خلفي لعرض صفحاته:

1. نزّل ملفات المشروع أو استنسخ المستودع.
2. افتح `index.html` في المتصفح، أو استخدم خادم ملفات ثابتًا محليًا.

لإكمال نموذج التسجيل، يلزم اتصال بالإنترنت حتى يتم تحميل المكتبات الخارجية وإرسال الطلب عبر FormSubmit. ويتضمن المشروع أيضًا ملف `blockUser.json` المستخدم في التحقق من المشاركين السابقين.

## ملفات المشروع

```text
.
├── index.html              # الصفحة الرئيسية ونموذج التسجيل
├── aboutUs.html            # معلومات المسابقة والمتسابقون الأوائل والفيديو
├── Competition-results.html # صفحة النتائج
├── style.css               # تنسيقات الموقع
├── script.js               # التحقق من التسجيل وتجهيز وإرسال ملف PDF
├── blockUser.json          # بيانات المشاركين السابقين للتحقق من الفئات
└── images/                 # الشعارات وصور المتسابقين والفيديو
```
